SECTION 6: IF ANYTHING GOES WRONG

  Most Common Issues (& Solutions):

  ❌ "Render fails with missing packages"
     → install.packages(c("dataRetrieval", "dplyr", "ggplot2"))

  ❌ "Interactive map not visible"
     → Open _book/index.html in web browser (not RStudio Viewer)

  ❌ "DOCX download doesn't work"
     → Run: quarto render --to docx

  ❌ "Git shows 1000s of files modified"
     → Line ending issue: git config core.autocrlf true

  ➜ See PRE_PUSH_VERIFICATION.md → "Common Issues" for more
