TROUBLESHOOTING
================================================================================

STAGE 1 - Python won't run:
  → Verify venv is activated: see "source" or ".venv\Scripts\activate"
  → Check requirements installed: pip list | findstr pdfplumber pandas

STAGE 2 - Can't find station coordinates:
  → Check PDF's Table of Contents and Appendices
  → Look for "Station Locations" or "Monitoring Sites" table
  → Verify coordinates are lat/lon (not just station names)

STAGE 3 - No confirmed sites:
  → Check CSV columns match expected: station_id, lat, lon, ...
  → Verify format: lat/lon must be numeric (not quoted text)
  → Look at console output: did any sites fall outside HUCs?

STAGE 4 - Map doesn't show Pebble:
  → Verify file exists: other/output/pebble_nushagak_confirmed_sites.csv
  → Check CSV has data: at least 1 row (+ header)
  → Check RStudio console for error messages
  → Browser console (F12): any JavaScript errors?
