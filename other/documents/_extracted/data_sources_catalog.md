# Nushagak River Watershed Water Quality Data Sources Catalog

## Context & Scope
This catalog compiles both archived public databases and non-repository literature (grey literature, regulatory baseline reports, academic studies, and tribal monitoring) for the Nushagak River drainage (HUC6 190303). It supports the project goal of creating a comprehensive baseline water quality summary for the watershed.

---

## 1. Primary Public Repositories

| Data Source / Repository | Access Link | Expected Data & Parameters |
| :--- | :--- | :--- |
| **Water Quality Portal (WQP)** *(EPA WQX, CDX & USGS NWIS)* | https://www.waterqualitydata.us/ | Physical/chemical properties (pH, DO, temperature, conductivity, turbidity), nutrients (N, P), heavy metals, trace elements, biological sampling across HUCs `19030301`–`19030305`. |
| **USGS National Water Information System (NWIS)** | https://waterdata.usgs.gov/nwis | Streamflow, continuous water temperature, suspended sediment concentration (SSC), long-term water chemistry at active and historic stream gages. |
| **Alaska DEC Water Quality Monitoring Portal** | https://dec.alaska.gov/water/ | Ambient WQ monitoring reports, CWA Section 303(d) listings, Integrated Water Quality Assessment reports, DEC grant-funded project data. |

## 2. Regulatory Studies & Environmental Baseline Data (Non-Repository)

| Source / Project | Access Link | Expected Data & Parameters |
| :--- | :--- | :--- |
| **EPA Bristol Bay Watershed Assessment (BBWA)** | https://www.epa.gov/bristolbay | Multi-year synthesized surface water chemistry, baseline trace metals (copper, molybdenum, zinc), acid-generating potential, toxicity benchmarks. |
| **Pebble Project EIS & Environmental Baseline Document (EBD)** | https://www.pebbleprojecteis.com/ | High-frequency surface and groundwater chemistry (2004–present), dissolved/total metals, alkalinity, stream temperature loggers, discharge relationships in Mulchatna/Koktuli drainages. |
| **ADNR Division of Mining, Land & Water** | https://dnr.alaska.gov/mlw/ | Water use permits, baseline hydrologic monitoring, state land mining exploration sampling submissions. |

| Source / Organization | Access Link | Expected Data & Parameters |
| :--- | :--- | :--- |
