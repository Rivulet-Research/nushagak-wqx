# Collaboration Documentation

This folder contains guides for working with the Nushagak River water quality project.

**SETUP.md** — How to clone, install, render, and view the book. Start here.

**VERIFICATION.md** — Tests to run before pushing to GitHub. Run this before each commit.

---

## Quick Start

1. Follow SETUP.md (10 minutes)
2. Read the rendered book in your browser
3. Before each commit, use VERIFICATION.md

---

## Project Basics

Data sources: EPA WQP, USGS NWIS (public repositories)

Spatial scope: Four HUC8 sub-basins (19030301, 19030302, 19030303, 19030304)

Chapters: 11 (organized in three parts)

Safe to edit: All files in `chapters/` folder

Do not edit: `_quarto.yml`, `.github/workflows/`, `references.bib`
