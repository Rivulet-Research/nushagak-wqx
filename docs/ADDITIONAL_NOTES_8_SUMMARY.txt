ISSUE 1: GITHUB PAGES DIRECTORY STRUCTURE
────────────────────────────────────────────────────────────────────────────

ORIGINAL CONCERN:
"In order to publish to github pages i think i need the book content in 
folder in the root called 'docs'."

RESOLUTION:
No change needed. Current setup is correct.

Current flow:
  1. quarto render → outputs to _book/ folder
  2. GitHub Actions workflow runs
  3. Uploads _book/ as artifact
  4. GitHub Pages serves the artifact

Why this is correct:
  • Keeps generated files out of git (cleaner repository)
  • _book/ is excluded from .gitignore
  • GitHub Actions handles the deployment
  • Site updates automatically on push

Alternative approach (not recommended):
  • Change _quarto.yml output-dir to "docs"
  • Commit docs/ folder to git
  • Enable GitHub Pages from docs/ in repo settings
  → This pollutes the repository with generated files

Current approach is the standard GitHub Actions + GitHub Pages pattern.

For details: See _docs_collaboration/GITHUB_PAGES_DEPLOYMENT.md
