BEFORE EVERY COMMIT:

1. Test render:
   $ quarto render --to html
   Expected: "Output created: _book\index.html" (last line)

2. Check for incomplete content:
   $ grep -r "TODO\|FIXME\|XXX" chapters/
   Expected: Empty (no matches)

3. Verify HUC8 consistency:
   $ grep -r "five HUC\|19030305" chapters/ | grep -v excluded
   Expected: Empty (no matches unless explaining exclusion)

4. Review git status:
   $ git status
   Expected: Only your intended changes

5. Commit with message:
   $ git commit -m "Update Chapter X: specific change"

6. BEFORE PUSHING, render again (yes, again):
   $ quarto render --to html

7. Push:
   $ git push origin main

8. Monitor deployment:
   - Check GitHub Actions: https://github.com/Rivulet-Research/nushagak-wqx/actions
